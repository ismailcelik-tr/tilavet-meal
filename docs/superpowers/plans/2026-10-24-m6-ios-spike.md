# M6 iOS Spike Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run the tiny ASR + position engine + meal playback on İsmail's iPhone 17, prove the Swift port equals Python, and measure accuracy, latency, resources, battery, background behaviour and package options.

**Architecture:** A pure Swift package `TilavetCore` mirrors the Python core and is verified on the Mac against golden vectors exported from Python. A thin SwiftUI app (`TilavetApp`, XcodeGen) adds audio I/O, sherpa-onnx and logging; Mac-side Python scripts drive device runs over `xcrun devicectl` and score them with the existing evaluation code.

**Tech Stack:** Swift 6 / SwiftUI / AVFoundation, XcodeGen 2.46, sherpa-onnx v2.0.0 `ios-shared-onnxruntime-static` xcframework, Python 3.12 (uv) for golden export and scoring.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-10-24-m6-ios-spike-design.md`.
- Device: iPhone 17, paid developer account, phone stays unlocked; runs are launched from the Mac with `xcrun devicectl`.
- Swift results must equal Python exactly (events, plays, alignments, normalized text). Any mismatch is a bug, not a tolerance.
- Engine rules frozen at `398b251`; the port does not change behaviour.
- Raw and derived data stay out of git (`data/`, app resources, golden files). Only code, project spec and reports are committed.
- Audio session: `.playAndRecord` + `.allowBluetoothA2DP`; never `.allowBluetooth` (HFP).
- Window 12 s, hop 1 s, cooldown 300 s, max wait 15 s (same as Python).
- Code, comments, commits in English; user's CLAUDE.md style (early return, constants, `{}` always, minimal public surface: `public` only what the app uses).

### Task 2: TilavetCore — normalize and Tanzil

**Files:** `ios/TilavetCore/Package.swift`, `Normalize.swift`, `Tanzil.swift`, `Golden.swift`, `NormalizeTests.swift`; `.gitignore` adds `ios/**/.build`, `ios/TilavetApp/Vendor`, `ios/TilavetApp/Resources`, `ios/TilavetApp/*.xcodeproj`.

**Interfaces:**
```swift
public func normalize(_ text: String) -> String
public struct AyahRef: Hashable, Comparable, Codable { public let sura: Int; public let aya: Int }
public struct MealUnit: Hashable { public let sura: Int; public let first: Int; public let last: Int; public let text: String; var refs: [AyahRef] }
public func parseTanzil(_ text: String) throws -> [AyahRef: String]
func stripBasmala(_ ref: AyahRef, _ text: String) -> String
public func mealUnits(_ meal: [AyahRef: String]) -> [MealUnit]
```

Normalize works on Unicode scalars, mirroring the Python regexes:
- drop U+0610–U+061A, U+064B–U+065F, U+0670, U+06D6–U+06ED, U+0640;
- map أ إ آ ٱ → ا, ى → ي, ة → ه, ؤ → و, ئ → ي, ی → ي, ک → ك;
- any scalar outside U+0621–U+064A that is not whitespace (`Character.isWhitespace` vs Python `\s` — the golden test decides) → space;
- collapse whitespace runs to one space, trim.

- [ ] Write `NormalizeTests.testGolden` (every pair equal; report the first 5 mismatches) and `testTanzil` (strip basmala of 2:1, keep 1:1; units merge identical consecutive texts).
- [ ] `swift test --package-path ios/TilavetCore` → fails (no symbols). Implement. → passes.
- [ ] Commit `Port normalization and Tanzil parsing to Swift`.

### Task 3: TilavetCore — index and alignment

**Interfaces:**
```swift
public final class QuranIndex {
  public static func build(_ ayahs: [AyahRef: [String]]) -> QuranIndex
  let words: [String]; let refs: [AyahRef]
  func ordinal(_ ref: AyahRef) -> Int; func ordinalAt(_ position: Int) -> Int; func ref(_ ordinal: Int) -> AyahRef
  func span(_ ref: AyahRef) -> Range<Int>; func positions(_ word: String) -> [Int]
}
struct Alignment: Equatable { let score: Int; let corpusStart: Int; let corpusEnd: Int; let pairs: [(hyp: Int, pos: Int)]; let hypEnd: Int }
func indelSimilarity(_ a: String, _ b: String) -> Double   // rapidfuzz Indel.normalized_similarity
func localAlign(_ hyp: [String], _ corpus: [String], _ lo: Int, _ hi: Int) -> Alignment?
func alignAll(_ hyp: [String], _ corpus: [String], _ lo: Int, _ hi: Int, _ minScore: Int) -> [Alignment]
```

- `indelSimilarity` = `1 - (len(a) + len(b) - 2·LCS) / (len(a) + len(b))` over Unicode scalars; both empty → 1.
- `localAlign` copies the Python DP exactly, including tie-breaking: `max` over `(value, direction)` tuples compares value first, then direction (DIAG=1 < UP=2 < LEFT=3), so on equal values LEFT wins, then UP, then DIAG. Strict `value > best` for the best cell.

- [ ] Write `AlignTests.testGolden` (index built from `data/raw/quran-simple-clean.txt` via `normalize(stripBasmala(...))`; every case equal) + `testSimilarity` (`("abc","abd")` → 2/3, empty pair → 1).
- [ ] Fail → implement → pass. Commit `Port Quran index and alignment to Swift`.

### Task 4: TilavetCore — engine and policy

**Interfaces:**
```swift
public struct EngineConfig { /* every field of Python EngineConfig with the same defaults, incl. acquireRivalVotes 2, pastMargin 3 */ }
public enum Mode: String { case acquire, track }
public enum Event: Equatable { case confirmed(t: Double, ref: AyahRef, mode: Mode, score: Int); case lost(t: Double) }
public final class PositionEngine { public init(_ index: QuranIndex, _ config: EngineConfig = .init()); public func feed(_ t: Double, _ words: [String]) -> [Event] }

public final class EmissionPolicy { public init(_ units: [MealUnit], cooldownS: Double); public func on(_ event: Event) -> Play? }
```

Port `tracker.py` line by line (`_acquire`, `_candidate_alignments` with `(index, word)` voters and optional limit, `_track`, `_margin`, `_distinct_prefixes`, `_overlaps`). Python iteration orders that matter:
- `sorted(support.items(), key=(-votes, diagonal))`;
- `Counter` insertion order is irrelevant after sorting;
- `max(alignments, key=score)` returns the **first** maximum — use a manual loop, not `Array.max(by:)` (which returns the last).
- `min(..., key=(-hyp_end, distance))` returns the first minimum.

- [ ] Write `EngineTests.testGolden`: for each of 80 streams feed windows through `PositionEngine` + `EmissionPolicy(cooldownS: 300)`; records equal (`t` compared exactly as Double).
- [ ] Fail → implement → pass. Commit `Port position engine and emission policy to Swift`.

### Task 7: Live listening and meal playback

**Files:** `AudioInput.swift`, `MealOutput.swift`, `Pipeline.swift`, `RunLog.swift`, `Metrics.swift`, `ContentView.swift`.

- `AudioInput`: `AVAudioSession` `.playAndRecord`, options `[.allowBluetoothA2DP]`, `setPreferredInput(builtInMic)`; `AVAudioEngine.inputNode` tap → `AVAudioConverter` to 16 kHz mono Float32 → chunks with `CACurrentMediaTime()`; interruption and route-change observers logged.
- `Pipeline`: serial queue; drains chunks, feeds `LiveSession` (newest-window skip like `live.py._pump`), forwards `started` player events to `MealOutput`, publishes the latest meal to the UI.
- `MealOutput`: `AVAudioPlayer` per unit file; logs `Playback` with wall time.
- `RunLog`: `Documents/<start>/{mic.wav, live.jsonl, metrics.jsonl}`; jsonl schema equal to `scripts/loopback.py:jsonable`; flushed every 10 s (M5 lesson: never only in memory).
- `Metrics` every 5 s: resident memory (`task_vm_info.phys_footprint`), process CPU % (`task_threads` sum), `ProcessInfo.thermalState`, `UIDevice.batteryLevel` (monitoring on), ASR seconds of the last window.
- UI: Start/Stop, meal text + `[s:a]` (+ "birlikte çevrilmiştir" note), status line; launch args `--autostart`, `--duration S`, `--threads N`.

- [ ] İsmail: Fatiha with the CMF Buds (meals heard, in order). Commit `Add live listening and meal playback`.

### Task 8: Loopback measurement on device

**Files:** `scripts/device_loopback.py`.

- Builds `data/derived/m6/session.wav`: 10 s lead + the 8 M4 live-session streams separated by 5 s silence; truth = their segments shifted by each start.
- Launches the app (`--autostart --duration <len + 30>`), plays the wav on the MacBook speaker (same volume rule as `loopback.py`), pulls the run, finds the offset with `estimate_offset(reference, device_mic)`, scores plays with `score_stream` per stream span, summarises metrics (RTF p50/p90, memory max, CPU median, thermal max).
- Writes `reports/m6-device.md`. Gates: wrong 0, recall ≥ 85 %, meal start − unit end p50 ≤ 1.5 s / p90 ≤ 3 s, RTF ≤ 0.3, memory ≤ 300 MB, thermal below `serious`.
- Note: one engine session spans all 8 streams (switching passages = reciter change), unlike M4's per-stream sessions.

- [ ] Run (~35 min, unattended). Commit script + report `Measure the iPhone pipeline over loopback`.
